# DailyCalculas

## 功能介绍

一个简洁的每日微积分练习网页，每天提供一道极限题和一道积分题，点击题目公式即可查看中文过程解析。

- 按北京时间每天零点切换题目；重新显示页面时也会检查日期并更新。
- 极限与积分各包含 8 种题型，通过题型轮换和整数参数变化生成每日题目，完整组合每 88 天循环。
- 使用 KaTeX 排版独立公式与行内公式，中文解析采用随网站提供的 Noto Serif SC 字体，桌面字号 18px、手机 17px。
- 答案链接保留题目日期，跨日后仍可查看对应解析。
- 页面使用暖白底、衬线标题和枣红色悬停效果，适配电脑与手机。
- `dist/preview.html` 是内嵌样式、脚本与字体的单文件版本，下载后可直接打开。
- 每日题目由内置题库生成，不依赖外部 AI 或定时任务，当前不会自动生成全新题型。

## 本地预览

项目是无需构建的静态网站，网页文件位于 `dist/` 目录。安装 Python 后，在项目根目录运行：

```sh
python -m http.server 4173 --directory dist
```

然后在浏览器打开 <http://localhost:4173>。

## 本地检查

安装 Node.js 后，在项目根目录运行：

```sh
npm ci --no-audit --no-fund
npm test
```

检查包括网页脚本语法、独立与行内 LaTeX 公式渲染、中文解析是否齐全、每日题目切换，以及单文件版本是否与源码一致。这些检查不能代替对数学答案正确性的审核。

修改页面、题库、脚本或样式后，先重新生成单文件版本再检查：

```sh
npm run build:preview
npm test
```
